# Ende Standard Library

[![JSR @ende](https://jsr.io/badges/@ende)](https://jsr.io/@ende)
[![ci](https://github.com/theende/std/actions/workflows/ci.yml/badge.svg)](https://github.com/theende/std/actions/workflows/ci.yml)

High-quality APIs for [Ende](https://ende.sh) and the web. Use fearlessly.

> [!IMPORTANT]
> The Standard Library is published on [JSR](https://jsr.io/@ende) under the
> `@ende` scope, one package per module (e.g. `@ende/assert`). Coming from
> Deno's `@std/*` packages? Replace the `@std/` scope with `@ende/`; module
> names and exports are the same.
